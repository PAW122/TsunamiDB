HTTP API Overview

HTTP API is the language-neutral interface to TsunamiDB. Base URL: http://localhost:5844.

Endpoint Index

MethodPathUseDocs
POST/save/{table}/{key}Save raw bytes or nested JSON.Key-Value
GET/read/{table}/{key}Read raw bytes or selected nested JSON paths.Key-Value
GET/free/{table}/{key}Delete a key and mark data as reusable.Key-Value
POST/save_encrypted/{table}/{key}Encrypt and save bytes.Encrypted
GET/read_encrypted/{table}/{key}Read and decrypt bytes.Encrypted
POST/save_inc/{table}/{key}Append, insert or overwrite an incremental-table entry.Incremental
GET/read_inc/{table}/{key}Read incremental entries by id, key, first N or last N.Incremental
GET/delete_inc/{table}/{key}Delete incremental table metadata and backing file.Incremental
POST/GET/PATCH/DELETE/rel/..., /rel/sqlRelational schemas, row CRUD, selects, compact SQL, indexes and compaction.Relational
POST/subscriptions/enableMint a one-time subscription auth key.Subscriptions
POST/subscriptions/disableUnsubscribe active sockets from one key.Subscriptions
GET/key_by_regex/{table}?regex=...&max=...Find keys in one table by regex.Meta
GET/healthRuntime health and stats.Meta

Status Codes

StatusMeaning
200Operation completed.
400Invalid URL args, missing required header, invalid JSON or invalid numeric header.
404Key or incremental entry not found.
405Wrong HTTP method.
409Incremental entry_key already exists.
500Storage, encryption, index, network or serialization failure.
