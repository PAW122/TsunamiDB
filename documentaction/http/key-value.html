HTTP Key-Value

Basic operations save, read and delete bytes in a table under a key.

POST /save/{table}/{key}

Reads the request body as bytes, stores it in table, and associates it with key. Re-saving the same key replaces metadata and marks the old span for defragmentation.

InputValue
BodyAny bytes. Use --data-binary for curl.
Header modeOptional. Set save_nested_json to extract nested JSON payloads.
Success bodysave
 
curl -X POST http://localhost:5844/save/users/user-1 \
  -H "Content-Type: application/octet-stream" \
  --data-binary "Hello, TsunamiDB"

GET /read/{table}/{key}

Returns the decoded user bytes. If the key is not local, TsunamiDB asks connected P2P peers.

curl http://localhost:5844/read/users/user-1

GET /free/{table}/{key}

Removes the key from the map and marks the stored data range as free. If the value has nested JSON chunks, linked nested chunks are also cleaned up.

curl http://localhost:5844/free/users/user-1

Nested JSON Mode

Nested mode is for large JSON documents where selected fields should be stored as separate chunks. Send JSON to /save with header mode: save_nested_json. Any string value starting with @ becomes a nested value.

{
  "profile": {
    "name": "edgar",
    "bio": "@{\"links\":[\"https://example.com\",\"https://github.com\"]}"
  },
  "logs": "@[{\"ts\":1730000000,\"event\":\"LOGIN\"}]"
}
curl -X POST http://localhost:5844/save/users/user-2 \
  -H "Content-Type: application/json" \
  -H "mode: save_nested_json" \
  --data-binary @payload.json

Reading Nested Values

HeaderBehavior
noneReturns base JSON with unresolved nested pointers replaced by "*".
read_nestedExpands only listed paths and keeps other nested values as "*".
read_only_nestedReturns an object containing only the selected nested paths.

Header names are matched case-insensitively by Go's HTTP server. Paths can be space-separated, comma-separated, or a JSON array.

curl http://localhost:5844/read/users/user-2 -H "read_nested: profile.bio logs"
curl http://localhost:5844/read/users/user-2 -H "read_only_nested: [\"profile.bio\"]"
