Meta and Health

Utility endpoints for key discovery and runtime status.

GET /key_by_regex/{table}?regex=...&max=...

Returns keys from one table matching a regular expression. max is optional; 0 means no explicit limit at the route level.

curl "http://localhost:5844/key_by_regex/users?regex=^user-&max=100"

Response:

["user-1","user-2"]

GET /health
