Go Lib

The Go library is an in-process client package at github.com/PAW122/TsunamiDB/lib/dbclient. Package name in code is TsuClient.

Install

go get github.com/PAW122/TsunamiDB/lib/dbclient@v0.8.0

Initialization

Read and ReadEncrypted require a NetworkManager instance. Call InitNetworkManager before reads, even for single-node local usage.

package main

import (
	"fmt"
	"time"

	TsuClient "github.com/PAW122/TsunamiDB/lib/dbclient"
)

func main() {
	TsuClient.InitNetworkManager(5843, []string{})  // optional
	TsuClient.InitPublicApi(5844)                   // optional
	_ = TsuClient.InitSubscriptionServer("5845")    // optional

	time.Sleep(500 * time.Millisecond)

	if err := TsuClient.Save("user-1", "users", []byte("hello")); err != nil {
		panic(err)
	}

	data, err := TsuClient.Read("user-1", "users")
	if err != nil {
		panic(err)
	}

	fmt.Println(string(data))
}

Encrypted Example

encKey := "very_secret_key"

if err := TsuClient.SaveEncrypted("api-token", "secrets", encKey, []byte("secret")); err != nil {
	panic(err)
}

plain, err := TsuClient.ReadEncrypted("api-token", "secrets", encKey)
if err != nil {
	panic(err)
}

Incremental Example

saved, err := TsuClient.SaveInc("activity", "events", []byte("first"), TsuClient.SaveIncOptions{
	MaxEntrySize: 128,
	EntryKey:     "evt-1",
})
if err != nil {
	panic(err)
}

entries, err := TsuClient.ReadInc("activity", "events", TsuClient.ReadIncOptions{
	Type: TsuClient.ReadIncByID,
	ID:   saved.ID,
})
if err != nil {
	panic(err)
}

fmt.Println(string(entries[0].Data))

Patch Example

Patch updates an existing value without sending the entire replacement value. For live editing, enable revision tracking and use PatchWithRevision so stale clients are rejected instead of applying edits to the wrong document version.

if err := TsuClient.Save("doc-1", "docs", []byte("Hello world")); err != nil {
	panic(err)
}

state, err := TsuClient.SetRevisionPolicy("doc-1", "docs", TsuClient.RevisionModeHistory)
if err != nil {
	panic(err)
}

snapshot, err := TsuClient.ReadWithRevision("doc-1", "docs")
if err != nil {
	panic(err)
}

updated, state, err := TsuClient.PatchWithRevision("doc-1", "docs", state.Rev, []TsuClient.PatchOperation{
	{Offset: 5, Insert: ","},
	{Offset: 7, Delete: 5, Insert: "TsuDB"},
})
if err != nil {
	panic(err)
}

fmt.Println(string(snapshot.Data), string(updated), state.Rev) // Hello world Hello, TsuDB 1

Subscriptions Example

A practical pattern is a live Online Users field. Start InitSubscriptionServer, subscribe clients to a table/key target such as stats/online-users, and update that key whenever the count changes.

Each connected WebSocket client then receives the new value automatically, which is a better fit than repeated polling when the UI should refresh immediately.

authKey, err := TsuClient.EnableSubscriptionForTargets([]TsuClient.SubscriptionTarget{
	{Table: "stats", Key: "online-users"},
})
if err != nil {
	panic(err)
}

fmt.Println("send this auth key to the WebSocket client:", authKey)

if err := TsuClient.Save("online-users", "stats", []byte("128")); err != nil {
	panic(err)
}

if err := TsuClient.DisableSubscriptionForTarget("stats", "online-users"); err != nil {
	panic(err)
}

Current Limitations

  • The Go lib currently does not expose typed wrappers for nested JSON mode. Use HTTP for that feature.
  • Read returns an error when NetworkManager is not initialized.
  • Public API and subscription server use goroutines; give them a short startup window before first request in tests or examples.
